# Gandiva - AI Deepfake Detection Platform

## Project Overview
A React/Vite website for Gandiva, an AI-powered deepfake and synthetic media detection platform.

## Tech Stack
- **Framework**: React 18 + TypeScript
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS 4
- **Routing**: React Router 7
- **Icons**: Lucide React
- **UI Components**: Radix UI / Shadcn

## Design
- **Color Scheme**: Black (#000), White (#fff), Orange (#f97316), Yellow/Amber (#fbbf24)
- **Style**: Inspired by sensity.ai - clean dark design with bold typography
- **Logo**: Custom SVG Gandiva bow logo (bow weapon from Hindu mythology)
- **Font**: Eagle Lake serif for the logo wordmark

## Pages
1. **Login** (`/`) - Authentication page with Google, Facebook, and Email login options
2. **Home** (`/home`) - Main landing page with hero, dashboard preview, stats, features, solutions, and CTA

## Running
- Dev server: `npm run dev` on port 5000
- Build: `npm run build`

## Key Features
- Gandiva bow SVG logo (orange/yellow bow with arrow)
- sensity.ai-inspired layout with bold hero section
- Live threat detection dashboard mockup
- Feature cards grid
- Industry solution sections with images
- Trusted organizations section
- Statistics section with gradient numbers
